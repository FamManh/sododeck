# Agent rules

Rules for every AI agent working in this repo (Claude Code, Codex, others). They apply on top of
`CLAUDE.md` and the constitution (`.specify/memory/constitution.md`).

## Commits and pull requests

- Do **not** add `Co-Authored-By:` trailers (or any other AI attribution line) to commit messages.
- Commit messages follow Conventional Commits (`feat(app): …`, `fix(model): …`, `chore: …`), small
  and focused.
