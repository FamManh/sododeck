# Data Model: Basic Canvas Editing (003)

003 adds **no document data** and no file-format change. Components, groups and connections are
the v1 `Node`, `Group` and `Edge` (see `specs/001-json-schema-v1/data-model.md`); their live form,
ids, cascade and undo are defined by 002 (`specs/002-yjs-model/data-model.md`). This document lists
what the canvas reads and writes, the UI-only state it adds, and the pure derived view models.

## Document fields the canvas uses

| Object | Field                            | Read for                              | Written by (002 operation)                              |
| ------ | -------------------------------- | ------------------------------------- | ------------------------------------------------------- |
| Node   | `id`                             | identity, React Flow node id          | never (generated by `add`)                              |
| Node   | `type`                           | kind tile, palette kind               | `add('nodes', { type, title: 'New <kind>', position })` |
| Node   | `title`                          | label, accessible name, outline       | `add`, `update('nodes', id, { title })`                 |
| Node   | `tech`                           | subtitle                              | — (inspector 008)                                       |
| Node   | `rules`                          | rule marker (non-empty list)          | —                                                       |
| Node   | `group`                          | group boundary, outline tree          | — (group editing 008/010)                               |
| Node   | `position`                       | placement                             | `add`, `update('nodes', id, { position })` on drag      |
| Group  | `id`, `title`, `parent`          | boundary label, nesting, outline      | —                                                       |
| Edge   | `id`, `from`, `to`               | endpoints                             | `add('edges', { from, to })`, `update` on reconnect     |
| Edge   | `label`, `protocol`, `direction` | pill, popover, end marker             | `update('edges', id, patch)` from the popover           |
| Deck   | `name`                           | top bar, inspector (nothing selected) | `updateMeta({ name })`                                  |

Deletes use `remove('nodes' | 'edges', id)` inside one `batch`; the cascade (edges removed, steps
and stickies kept and reported) is the model's.

Invariants the canvas relies on:

- Positions are whole numbers (rounded before writing).
- A node without `position` is shown at a display-only grid slot; nothing is written until the
  user moves it.
- An edge whose `from` or `to` is missing is not drawn (it is reported by 015).

## UI-only state (Zustand, never exported)

| State              | Shape                                                                     | Notes                                                 |
| ------------------ | ------------------------------------------------------------------------- | ----------------------------------------------------- |
| `selection`        | `{ nodes: Id[]; edges: Id[] }`                                            | replaces today's `selectedId`; pruned when ids vanish |
| `focusedId`        | `Id \| null`                                                              | roving tabindex target on the canvas                  |
| `leftTab`          | `'outline' \| 'palette'`                                                  |                                                       |
| `outlineCollapsed` | `Set<Id>` of group ids                                                    |                                                       |
| `labelsOn`         | `boolean`                                                                 | remembered in `localStorage` (try/catch)              |
| `popover`          | `{ kind: 'edge'; edgeId: Id } \| { kind: 'connect'; fromId: Id } \| null` |                                                       |
| `pendingDelete`    | `{ nodes: Id[]; edges: Id[] } \| null`                                    | open confirmation dialog                              |
| `announcement`     | `string`                                                                  | text for the live region                              |
| `jsonPanelOpen`    | `boolean`                                                                 | unchanged                                             |

Viewport (pan, zoom) stays inside React Flow; it is UI state and is not stored.

State transitions:

```text
selection:  click node/edge → [it] · shift/⌘-click → toggle · marquee → items inside · ⌘A → all nodes
            click pane / Esc → [] · after undo/redo that re-adds objects → the re-added ids
            any id no longer in the deck → dropped
delete:     Delete (selection ≠ ∅, focus not in a text field) → pendingDelete = selection
            Cancel/Esc → null · Confirm → batch remove → toast (6 s) → null
popover:    new edge → edge · double-click edge / Enter on edge → edge · C on node → connect
            Esc / outside click / commit → null · object removed → null
```

## Derived view models (pure functions, unit-tested)

| Function                                         | Input → output                                                                                   |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| `toFlowNodes(deck, selection, focusedId)`        | component nodes (164×50) + group-boundary nodes; reuses objects when inputs unchanged            |
| `toFlowEdges(deck, selection, labelsOn)`         | edges with smoothstep, 8 px radius, end markers by `direction`, label pill flag                  |
| `groupBounds(deck, positions)`                   | `Map<groupId, Rect>` from member boxes + padding, nested groups included                         |
| `buildOutline(deck)`                             | tree: groups (by `parent`) → nodes (by `group`); ungrouped nodes at root                         |
| `connectionCheck(deck, from, to, ignoreEdgeId?)` | `'ok' \| 'self' \| 'duplicate'` (duplicate in either direction)                                  |
| `connectTargets(deck, fromId, query)`            | options for keyboard connect: `{ id, title, disabled, reason }`, filtered by title               |
| `nearestInDirection(nodes, fromId, dir)`         | nearest node id within ±45° of the direction, or `null`                                          |
| `freeSpot(deck, center)`                         | `center`, offset by 24 px steps until no node sits exactly there                                 |
| `describeRemoval(result)`                        | confirmation text: "Delete Order Service and 2 connections? 1 flow step will be flagged broken." |
