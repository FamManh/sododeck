# Quickstart: validate 062 (fixable import errors)

Prerequisites: `pnpm install`, `pnpm dev` (app on :5173). Broken sample files live in
`packages/model/test/fixtures/broken/` (added by this feature, one per common mistake, SC-002).

## Automated

```sh
pnpm --filter @sododeck/schema test     # Zod → generic codes, pointers, S/I codes
pnpm --filter @sododeck/model test      # inspectDeckText, entries, ordering, catalogue + doc snapshot
pnpm --filter @sododeck/app test        # dialog, toast, panel copy, fidelity grouping + copy
pnpm lint && pnpm typecheck && pnpm test && pnpm build && pnpm e2e
pnpm bench                              # before/after: checkDeck on the 2,000-node deck (R8)
```

Expect: the catalogue doc `docs/file-format/problem-codes.md` is unchanged after `pnpm test`
(CI fails when it is stale; regenerate with `pnpm --filter @sododeck/model test -u`).

## Manual

1. **Refused file (Story 1).** Import `broken/missing-title-and-duplicate-id.sododeck`.
   Dialog `Couldn't open "…"` lists 2 problems with locations `/nodes/…`. Press **Copy
   problems**; paste into a text editor: valid JSON matching `contracts/problem-report.md`.
   Library unchanged.
2. **Not JSON.** Import `broken/not-json.sododeck`: one `invalid-json` entry with line and column.
3. **Newer version.** Import `broken/version-2.sododeck`: one `unsupported-version` entry.
4. **Determinism.** Import file 1 twice, copy both times: identical text (SC-003).
5. **Opened with problems (Story 2).** Import `broken/dangling-step-and-bad-picture.sododeck`.
   Toast `Imported "…" with 2 problems` → **Show**: one `step-without-connection`, one
   `picture-damaged`. **Open deck** opens it unchanged; the problems panel lists the step problem.
6. **Panel copy.** In the problems panel press **Copy problems**: `status: "opened"`, entries
   with `/flows/…` paths.
7. **Clipboard denied.** In site settings block clipboard, repeat 6: text area appears, focused
   and selected.
8. **Fidelity (Story 3).** Import Mermaid `broken/flowchart-fidelity.mmd` (style line, nested
   subgraph, click, node declared twice): items under Left out, Collapsed, Merged. **Copy
   report** → JSON matching the contract. Import a SQL file with a `CREATE VIEW`: item under Left
   out. Import a clean flowchart: `Everything was imported.`
9. **AI loop (SC-002).** Paste each broken fixture's copied report into an AI assistant with
   "Fix this .sododeck file" and the file; record rounds to a clean import in the PR report.
10. **Keyboard / screen reader (SC-006).** Do 1, 6 and 8 with keyboard only and VoiceOver on:
    "Copied problems" is announced.
11. **Large file (SC-004).** Import `broken/10k-problems.sododeck` (generated by a test helper):
    dialog opens < 1 s, shows 500 rows and `and 9,500 more`; copied JSON has 5,000 entries and
    `omitted: 5000`.
12. **Privacy.** With DevTools Network open during 1–8: no requests (the smoke e2e
    no-third-party check also stays green).
