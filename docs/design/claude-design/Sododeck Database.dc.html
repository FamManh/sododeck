Sododeck · Database pack (backlog 039–049) · direction B · Deck
The Database pack plugs into the type registry (030). A table is a B information card whose body is a list of column rows; connectors attach to rows and end in crow’s feet. The editor chrome (islands, rail, toolbars, menus, flyouts, drawer, tooltips, toasts) is the canvas-first editor from sododeck-canvas.js, drawn unchanged. One dialect per deck. Part A shows whole windows, Part B the components as 1180-wide plates. Light on the left, dark on the right.
