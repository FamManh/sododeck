# AI diagram skill

Describe a system to your own AI agent, or point it at a codebase, and get a `.sododeck` file you
simply import. The skill teaches the agent the deck model (cards, connectors, groups, flows and
rules), how to lay a deck out by hand so every flow reads left to right, and gives it offline
scripts that check the file the same way Sododeck does, so what it hands you opens cleanly.

Your agent runs on your side. Sododeck never sees your prompt, your code or the deck until you
import it, and even then it stays in your browser.

<a href={SKILL_REPO_URL}>Get the skill on GitHub (sododeck-diagram)</a>: install steps, example
decks and screenshots.

## Install

**Claude Code**

```text
/plugin marketplace add FamManh/sododeck-diagram-skill
/plugin install sododeck-diagram@sododeck
```

**Any agent with skills support**: clone the repository and link (or copy) its
`skills/sododeck-diagram` folder into the agent's skills folder, for example `~/.agents/skills/`
or `~/.claude/skills/`. Update with `git pull`.

**Any other agent**: put the `sododeck-diagram` folder in your project and add one line to your
`AGENTS.md` (or the agent's instructions file): "To write or edit a Sododeck deck, follow
`sododeck-diagram/SKILL.md`."

The scripts need Node.js 20 or newer and no network.

## Prompts that work

**From a description**

> Make a Sododeck deck of our checkout: web shop, API gateway, order service, a payment provider,
> Kafka and Postgres, plus the checkout flow from pressing Pay to the confirmation email.

**From a codebase**: say what the deck is about and which flows you want to play.

> Use the sododeck-diagram skill in codebase mode, detail faithful. Draw how an order is
> fulfilled, from the code in `services/orders`. Flows I want to play: place order, courier
> assigned, refund.

Every card and connector gets a link to the code it came from, anything that looks wrong in the
code becomes a "Gap" note, and the agent ends with a fidelity report.

**Update an existing deck**

> Here's checkout.sododeck. Add a refund flow: support asks the order service for a refund, it asks
> the payment provider, then records it. Don't change anything else.

The agent keeps every existing card and id, and shows you a diff (added, changed, removed) before
it hands the file over.

**From another format**

> Turn this Mermaid sequence diagram into a Sododeck deck with a flow.

Mermaid, C4 text and OpenAPI work the same way.

Dials you can name in the prompt: detail (`simplified`, `balanced`, `faithful`) and audience
(`engineer`, `mixed`, `executive`).

## Import

Open Sododeck, then **Library → Import**, or drop the file on the library. Cards keep the places
the agent gave them; flows play step by step right away.

If the import reports problems, press **Copy problems** and paste the result back to your agent.
The skill reads the same problem codes, paths and fix hints, and fixes the file.
