## Getting started

1. Open the app. There is no sign-up.
2. Draw nodes and edges, or paste a `.sododeck` file.
3. Your deck is saved in this browser. Export it to keep a backup.

## AI deck skill

Let your own AI agent write decks you can import: [AI deck skill](/docs/ai-skill).

## File format

Decks are stored as JSON that conforms to the schema at `https://sododeck.com/schema/v1.json`.
