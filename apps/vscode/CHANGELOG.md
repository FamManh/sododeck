# Changelog

## Next

- Opens `.sododeck.md` notes as a canvas, so one folder works in VS Code and Obsidian. Text you write outside the generated part of a note is kept on save; a Markdown file without the Sododeck marker stays a text file.
- Pictures in notes: links written by Obsidian resolve inside the workspace.
- New commands: **New Sododeck note** and **Copy as .sododeck** (for `.sododeck.json` files). **New Sododeck deck** is now **New Sododeck**.

## 0.1.0

- First release: open, edit, save and revert `.sododeck` files as a canvas; follows the file on disk; pictures embedded or next to the deck; light and dark theme; New deck and Open in web commands.
